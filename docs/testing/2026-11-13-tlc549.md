# TLC549 验证（2026-11-13）

以下是实验代码曾经启用时的历史验证记录。自 0.5.1 起 TLC549 由编译期硬开关屏蔽，默认验证不再编译或注册该通道。

- PlatformIO：`nodemcuv2`、`nodemcuv2_ap`、`nodemcuv2_tlc549` 均构建成功。TLC549 环境静态 RAM 45,788 / 81,920 字节，Flash 322,543 / 1,044,464 字节。
- `./tools/test_native.ps1`：345 项既有契约断言、507 项 TLC549 断言、64 项网络断言通过。GPIO 替身覆盖 MSB 优先、每帧八个下降沿、两帧间转换等待、丢弃上一转换结果、三脚冲突、采样间隔、0/255 边界与只读行为。
- `tests/check_capabilities.py`：使用 Android_WIFI 提交 `2732327` 的 Schema 验证基础与 TLC549 构建的实际序列化输出，核对清单版本和 4 KiB 响应预算。
- 未烧录、未实测电平转换、光敏电路或安卓真机。接线后先用 0 V、半参考电压、满参考电压检查读数。
