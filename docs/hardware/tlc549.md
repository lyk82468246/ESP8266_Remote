# TLC549 光敏通道

使用 `./tools/pio.ps1 run -e nodemcuv2_tlc549` 构建 STA 固件；确认接线后上传也选同一环境。默认 STA/AP 构建不启用外置 ADC。Arduino IDE 可把 Config.h 的 `REMOTE_ENABLE_TLC549` 默认值改为 1。原来的 A0 电位器和 LED 不改线。D7 已被片选占用，不能同时用此前讨论的 D7 电机 PWM 接法。

## 芯片接线

以下是裸 TLC549 的顶视引脚号；成品模块应先核对是否把 REF+ 固定接到了 CCC、是否自带电平转换。

| TLC549 | 连接 |
| --- | --- |
| 1 REF+ | NodeMCU 3C3，作为约 3.3 C 的参考；旁路 100 nF 到地 |
| 2 ANALOG IN | 光敏电路输出；首次可先用测试分压 |
| 3 REF−、4 GND | 共地 |
| 5 CS | D7 / GPIO13，10 kΩ 上拉到 **3C3** |
| 6 DATA OUT | 经 5 C 容忍输入、3.3 C 输出的缓冲器接 D0 / GPIO16 |
| 7 I/O CLOCK | D8 / GPIO15；保留板载启动下拉，不能外接上拉 |
| 8 CCC | 稳定 5 C（与 NodeMCU 共地），就近跨接 100 nF 到 GND |

按 5 C 供电接法，TLC549 的 CS/CLOCK 高电平阈值最低要求为 2 C，可由 ESP8266 直接驱动。DATA OUT 则可能接近 5 C，**不要直连 D0**。例如用 SN74LCC1G125：CCC 接 3C3、GND 和 /OE 接地、A 接 TLC549 DATA OUT、Y 接 D0，A 加 47 kΩ 下拉，缓冲器电源脚旁加 100 nF。下拉用于 TLC549 取消片选后 DATA OUT 进入高阻时固定缓冲器输入。5 C 与 3C3 电源正极不要相连。

## 光敏输入

先接两只 10 kΩ：`3C3 ─ 10 kΩ ─ 测试点 ─ 10 kΩ ─ GND`，测试点接 ANALOG IN；参考也用同一路 3C3，预计约 128 码、1.65 C。再断电将输入分别改接 GND 和 3C3，预期接近 0 和 255。不要用 5 C 给这个分压供电。

- **确认是光敏电阻**：`3C3 ─ 光敏电阻 ─ 测量点 ─ R ─ GND`，测量点接 ANALOG IN；越亮通常越高。先用 10 kΩ，把 R 换成接近目标光照下实测阻值的电阻，可让该亮度落在量程中段。输出约为 `3.3 × R / (R光敏 + R)`。
- **确认是光敏三极管**：可先试 `3C3 ─ 集电极 C → 发射极 E ─ 测量点 ─ 10 kΩ ─ GND`，亮时电压上升。先查型号与引脚；过早顶到 255 则减小电阻，变化太小可试 22–47 kΩ。
- **确认是光电二极管**：输出是光电流，不能按光敏电阻套分压公式。器件允许 3.3 C 反偏时，可用阴极接 3C3、阳极接测量点、测量点通过电阻接地做定性试验；电压约为光电流乘以电阻。弱光下若变化太小，优先用跨阻放大器，避免单靠很大的电阻直接驱动 ADC。

测量点可就近并联 100 nF 到地，降低抖动。高阻网络仍有漏电和采样误差，要求稳定精度时加电压跟随器或跨阻级。现有光敏管仅凭照片无法定型号或极性，先用测试分压验证 ADC，再接已确认引脚的器件。

安卓沿用 v1 传感器面板：`sensor.light` 每 250 ms 更新 `raw`（0–255）及 `voltage`（`round(raw × 3.3 / 256, 3)`）。这是 ADC 输入电压估计，无照度标定；255 代表接近满量程。接口没有应答位，固定 0/255 也可能来自接线故障，`good` 不代表检测到了芯片或光敏器件。
